# Data Analyse Learning List

This repository is a complete, exportable 24-week Data Analysis + Data Science learning program tailored for Marketing, Finance, SaaS, and Retail. It is designed to be used offline: clone, install, run notebooks/scripts, and export outputs.

Repository quick links:
- Calendar: calendar/24-week-day-by-day.md
- Full weekly curriculum: curriculum/weeks_full.md
- Notebooks starters: notebooks/
- Capstones: capstones/{marketing,finance,saas,retail}
- Datasets: datasets/
- Source modules: src/
- Tests: tests/
- CI: .github/workflows/ci.yml

How to use (summary):
1. Clone the repo: git clone https://github.com/cjx1Alyssa/data-analyse-learning-list.git
2. Create and activate virtual environment
3. pip install -r requirements.txt
4. Run tests: pytest -q
5. Run a week notebook (example): python notebooks/week01_kpis.py or open in Jupyter
6. Run demo: streamlit run deploy/streamlit_app.py
